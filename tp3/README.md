# TP3 — Layouts and widget experimentation

This TP focused on learning how Flutter handles layout and composition. It includes several small experiments that helped me understand how widgets are stacked and arranged.

## Included projects

- `3.1/exercice1`: a simple notification badge exercise using `Stack`
- `demo_app`: a simple demonstration app to practice UI building
- `partie_B`: a mini project centered around item listings and availability logic

## What I practiced

- basic layout composition with `Column`, `Row`, and `Stack`
- using containers, icons, text, and positioning
- building small UI prototypes quickly
- testing visual hierarchy and spacing
- improving my understanding of widgets as reusable blocks

## Reflection

This was one of the most important TPs for learning Flutter visually. I started to feel more comfortable designing interfaces and understanding how layout decisions affect the final screen.
