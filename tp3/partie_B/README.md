# TP3 - Partie B

This project was part of my first steps learning Flutter. It is not a final app, but a practical exercise to understand how to structure a small application and work with real data concepts.

## What I learned here

- how to represent data with models and simple classes
- how to load sample data asynchronously
- how to write rules such as checking whether a listing is available
- how to think in terms of app logic and UI separation

## Main idea

The app simulates a small marketplace or local exchange interface. It loads several listings and checks whether each one can be reserved or exchanged.

## Why this matters

This exercise helped me understand that a good Flutter app is not only a screen with components. It also needs clean logic, coherent data, and a clear flow.

## Reflection

This project is a good example of my beginner learning path: simple, direct, and focused on understanding the fundamentals before moving to more polished interfaces.
