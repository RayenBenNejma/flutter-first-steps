# TP4

This project marks a step toward a more polished Flutter interface. It was part of my learning process to improve UI composition, design consistency, and app structure.

## What I practiced

- better use of colors and spacing
- more organized screen layout
- card and list design patterns
- creating a cleaner first screen inspired by a local marketplace concept

## Why this project matters

By this point, I was moving from simple exercises to more complete application ideas. The goal was to make the interface feel cleaner and more realistic while still keeping the code simple and approachable.

## Reflection

This TP reflects an important stage in my learning: I was starting to understand that Flutter is not just about syntax, but also about how design and user experience work together.
