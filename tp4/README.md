# TP4 — Improving the interface and polishing the app

This TP was about making the app feel more complete and visually coherent. The goal was to practice interface design and structure more carefully than in the earlier beginner projects.

## What I practiced

- design consistency with colors and spacing
- cleaner card-based UI composition
- app branding and visual identity
- creating a more realistic landing screen for a local exchange app

## Main project

The main project in this folder is `tp4/`, which has a more polished LocalSwap-inspired interface and demonstrates how UI quality evolves with practice.

## Reflection

By this point, the apps were no longer just test examples. They were starting to look like real learning prototypes with a clearer design direction.
