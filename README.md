# Flutter TP Collection

This folder contains my first Flutter learning projects. They are not production apps yet, but they represent the first steps in learning the basics of Flutter: widgets, layouts, states, models, and UI design.

## Overview

- TP1: first contact with Flutter, buttons, interactions, and visual feedback
- TP2: local data model and basic logic for a local exchange concept
- TP3: layout exercises, structured widgets, and UI experimentation
- TP4: a more polished LocalSwap-inspired interface
- TP5: work in progress / next learning step

## Learning purpose

These projects helped me understand:

- how Flutter apps are structured
- how to use Material widgets
- how state and interactions work
- how layout composition works with columns, rows, and stacks
- how to organize simple project architecture and design small screens

## Notes

The apps here are intentionally simple. They show a learning journey, not a final finished product. Each project was part of my first steps with Flutter, and that is exactly what makes them valuable.
