# TP2 — Learning models and app logic

This TP introduced me to a more structured way of thinking in Flutter. Instead of only building screens, I started working with application logic and data models.

## What I practiced

- creating data classes for a simple app concept
- defining a product or listing model
- working with asynchronous functions
- checking business rules with simple logic functions
- understanding how logic and UI can be separated in a Flutter project

## Main concept

The app explores a local exchange idea: users can view listings, check their availability, and validate if an item can be reserved.

## Why this TP was important

This was the moment where I understood that Flutter is not only about visual design. It also involves modeling real-world objects and writing logic that makes the app meaningful.

## Files to look at

- `localswap/lib/main.dart`
- `localswap/lib/models/` for the application data model

## Reflection

This TP was a key step in moving from `Hello World`-style UI experiments to a more realistic app architecture.
