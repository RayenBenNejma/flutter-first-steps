# TP1 — First steps in Flutter

This project was one of my first experiences with Flutter. It helped me discover the basic structure of a Flutter app and understand how small UI changes can change the user experience.

## What I practiced

- creating a Flutter project from scratch
- understanding `MaterialApp` and `Scaffold`
- using simple widgets such as buttons and icons
- testing visual changes with hot reload
- learning how user interaction can trigger state updates

## Why this matters

At this stage, the goal was not to build a complete product. The goal was to learn the foundations: how Flutter renders widgets, how an app is organized, and how a screen can react to user actions.

## Files to look at

- `localswap/lib/main.dart` for the app code
- screenshots in this folder to see the progression of the project

## Reflection

This TP was an excellent first step because it showed that Flutter is a visual and component-based framework. Every small widget became a building block for bigger interfaces.
